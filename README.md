# Learning Management System (LMS)

## Project Description
The Learning Management System (LMS) is a web-based application designed to streamline educational workflows. It addresses the challenges of disorganized course materials, manual grading systems, and fragmented communication between educators and students. 

## Target Users/Stakeholders
* **Administrators:** Manage system configurations, user accounts, and institutional data.
* **Teachers/Instructors:** Create courses, publish learning materials, manage assignments, and grade submissions.
* **Students:** Enroll in courses, access educational content, submit assignments, and track academic progress.

## Objectives
* Provide a centralized digital hub for comprehensive course administration.
* Automate grading operations and assessment tracking to reduce manual workloads.
* Enhance teacher-student collaboration through structured communication modules.

## Key Features
* **User Authentication & Role Management:** Secure login access tailored for Admins, Teachers, and Students.
* **Course & Content Management:** Tools for uploading lectures, syllabi, and multi-media learning resources.
* **Assignment & Evaluation Module:** Digital submission portals equipped with automated or manual grading criteria.

## Technology Stack
* **Language:** Java
* **Architecture:** Object-Oriented Design (OOD)
